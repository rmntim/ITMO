# Функциональная схемотехника

Материалы курса «Функциональная схемотехника»: задания и документация, шаблон отчетов и проекты лабораторных работ. Лабораторные работы выполняются на отладочных платах **Saylinx**.

## Структура папки

| Папка | Содержимое |
| --- | --- |
| [docs](docs/) | Документы курса, задания лабораторных работ и требования к оформлению отчетов. |
| [typst-docs-template](typst-docs-template/) | Шаблон для подготовки отчетов в Typst. |
| [fec_saylinx_project_example](fec_saylinx_project_example/) | Пример проекта для платы Saylinx, созданный в **Quartus Prime 21.1.1 Lite Edition**. |
| [Labwork1](Labwork1/) — [Labwork4](Labwork4/) | Папки для материалов и результатов соответствующих лабораторных работ. |

## Подготовка отчетов

Используйте [шаблон Typst](typst-docs-template/) и оформляйте отчеты согласно требованиям из `docs/`. Основной файл шаблона — [`src/main.typ`](typst-docs-template/src/main.typ).

Для сборки PDF выполните из папки `typst-docs-template`:

```sh
typst compile src/main.typ document.pdf
```

Дополнительные инструкции доступны в [README шаблона](typst-docs-template/README.md).

## Проект для платы Saylinx

Пример предназначен для платы Saylinx с ПЛИС **ALTERA Cyclone IV EP4CE6F17C8**. Чтобы открыть его в Quartus Prime, используйте файл [`fec_saylinx_project.qpf`](fec_saylinx_project_example/fec_saylinx_project.qpf).

В папке проекта находятся модуль верхнего уровня на Verilog, настройки проекта и распиновка, документация на ПЛИС, схема платы и инструкция по установке ПО. Описание сигналов и правила безопасной работы с платой приведены в [README примера](fec_saylinx_project_example/README.md).

## Порядок работы

1. Изучите задание лабораторной работы и требования к отчету в `docs/`.
2. Используйте проект Saylinx как основу для выполнения задания в Quartus Prime.
3. Сохраняйте проект и результаты работы в соответствующей папке `LabworkN`.
4. Подготовьте отчет с помощью шаблона Typst и соберите PDF.
