## Симуляция

Нужны Icarus Verilog (`iverilog`, `vvp`) и `make`. Из папки `Labwork1`:

```sh
make test-register
```

При успешной проверке выводится `PASS: result_register`, временная диаграмма
сохраняется в `build/result_register.vcd` (открывается, например, в GTKWave).

```sh
make test
```

Полная проверка **не проходит**, пока не реализован `tb_boe.v`. Это предотвращает
ложное сообщение о готовности лабораторной при пустых модулях.

## Когда будет известен вариант

1. Определить интерфейс и реализовать оба базовых БОЭ.
2. Собрать параметризуемый модуль через `generate`; для сумматора, вычитателя
   и компаратора учесть связи между разрядами.
3. Соединить БОЭ с регистром в `boe_registered.v`; ширина регистра должна
   соответствовать ширине полного результата.
4. Заполнить тест БОЭ: таблица истинности, сравнение двух реализаций,
   независимая модель широкого элемента, крайние значения, WIDTH=1,
   запись и сброс составного устройства. Выполнить `make test`.
5. Заполнить данные титульного листа, описание, схемы, результаты и выводы.
